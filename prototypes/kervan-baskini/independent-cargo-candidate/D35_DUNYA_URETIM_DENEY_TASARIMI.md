# Natural generation benchmark design — separate from flat arena soak
Verified read-only server properties: live `level-type=minecraft:normal`, structures true, view 8, simulation 6; current QA `minecraft:flat`, structures false, view/sim 3, seed42. `GameWorld.openDimension` reuses overworld generator and sets a per-match seed from rnd.nextLong(); NativeArenaGame pins 24 chunks, waits for all loaded, then scans 63,684 cells in slices <=512/3ms. Existing CARAVAN_PREP ticks conflate world/chunk readiness and layout scanning, and current test flat generation is not a valid Noisium noise benchmark.

Proposed next experiment: use dedicated local QA run configuration only, no live world copy. Two freshly generated normal disposable QA test worlds (or equivalent independently verified fresh Fantasy dimensions), fixed same seed, structure generation true, same vanilla generator, same chunk targets and JVM/CPU/heap settings; one profile without Noisium and one with exact pinned version, other optimizer choices identical. Verify no existing target chunk files and no stale level reuse before start. Instrument elapsed wall time to all target chunks at FULL without synchronous force-load loops, CPU time, actual peak RSS and sampled heap, chunk count and final generation status; separate arena scan time and normal spawn bootstrap. Use warmup and AB/BA repetitions if disk budget allows, compare median/range not single result. Preserve test artifacts according to retention rule; do not delete existing worlds. Avoid producing extra application build copies. Include protected file before/after hashes and clean server shutdown. Current D35 does not run this experiment, since separate fresh natural worlds and instrumentation are required. Noisium remains compatibility-tested only, not demonstrated performance gain.
